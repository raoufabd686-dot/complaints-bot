# 🤖 Complaints Bot - One Mission

بوت ديسكورد لنظام الشكاوى داخل السيرفر.

---

## 🚨 الميزات

- نظام شكاوى احترافي
- تصنيف الشكاوى:
  - 🟢 ضد لاعب
  - 🔴 ضد إداري
  - 🟡 ضد قائد فصيل
- واجهة سهلة وسريعة

---

## 🎫 الاستخدام

اكتب:
!report

ثم اختر نوع الشكوى من القائمة.
